# PRD: ai_news_telegram

- 작성일: 2026-08-05
- 작성자: devjan
- 상태: 초안

## 1. 배경 및 목적
AI 관련 기술/비즈니스 뉴스를 매일 직접 찾아보는 대신, 현재 가장 화제가 되고 있는 소식을
자동으로 골라 텔레그램으로 요약 받기 위함. "AI 기술" 카테고리와 "AI 비즈니스" 카테고리를
나누어 각각 가장 인기 있는(Hot) 소식 5건씩 정리해서 전달한다.

## 2. 트리거 조건
- 이 스킬 자체는 정기 실행(스케줄링) 로직을 포함하지 않는다.
- `python src/main.py --mode daily` 또는 `--mode weekly`로 실행하면 그 시점 기준으로 1회
  검색·선별·발송을 수행한다.
- 정기 실행(매일 1회 / 매주 1회)은 스킬 완성 후 Hermes 또는 OS 스케줄러(cron/launchd)가
  모드별로 이 스크립트를 호출하는 방식으로 별도 구성한다 (이 PRD의 범위 밖).

## 3. 입력
| 항목 | 타입 | 필수 여부 | 설명 |
|---|---|---|---|
| `--mode` | 커맨드라인 인자 (`daily` \| `weekly`) | 필수 | `daily`는 최근 24시간, `weekly`는 최근 7일 이내 게시된 글을 검색 대상으로 함 |
| `TELEGRAM_BOT_TOKEN` | 환경변수 | 필수 | 저장소 공용 `.env`에 이미 등록되어 있음 |
| `TELEGRAM_CHAT_ID` | 환경변수 | 필수 | 저장소 공용 `.env`에 이미 등록되어 있음 |
| `ANTHROPIC_API_KEY` | 환경변수 | 필수 | 최종 Top5/Top5 랭킹 및 한국어 요약 생성(실행당 1회 호출)에 사용, 이미 등록되어 있음 |
| 발송 이력 DB 경로 | 설정값(코드 상수) | 선택 | 기본값: `skills/ai_news_telegram/data/sent_items.db` (이 스킬만 사용하는 캐시성 데이터이므로 공용 `data/`가 아닌 스킬 폴더 내부에 둠, `CLAUDE.md` 2절 참고) |

## 4. 출력
- **텔레그램 메시지 1건**: "📌 AI 기술 Hot 5" + "💼 AI 비즈니스 Hot 5" 두 섹션으로 구성.
  각 항목은 한국어 제목/한줄 요약, 원문 링크, 원 출처 지표(포인트·댓글수)를 포함한다.
- 카테고리별 후보가 5건 미만이면 있는 만큼만 포함하고, 메시지 상단에 "이번 실행에서는
  ○○ 분야 후보가 N건뿐입니다" 안내를 덧붙인다.
- 후보가 아예 0건인 카테고리는 해당 섹션에 "이번 기간 동안 발견된 소식이 없습니다"로 표시한다.
- **발송 이력 DB 반영**: 이번 실행에서 최종 발송된 HN item id를 기록해 다음 실행에서 같은
  글이 중복 발송되지 않게 한다.

## 5. 처리 흐름 (개요)
1. `--mode` 인자와 `.env`(`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `ANTHROPIC_API_KEY`) 로드
2. Hacker News Algolia API에서 AI 관련 키워드로 스토리를 검색한다. `daily`는
   `created_at_i` 최근 24시간, `weekly`는 최근 7일로 시간 필터링
3. 검색 결과에서 이미 발송 이력 DB에 있는 item id는 제외한다
4. 규칙 기반 점수식(`points + comments * 가중치`)으로 정렬하고, 제목/본문 키워드 매칭으로
   "기술" / "비즈니스" 카테고리로 분류해 카테고리별 상위 N건(예: 15건)을 후보 풀로 추린다
5. 후보 풀(기술+비즈니스, 최대 30건)을 Claude API에 1회 전달해 카테고리별 최종 Top5를 선정하고
   각 항목의 한국어 제목/한줄 요약을 구조화된 형식(JSON)으로 받는다
6. 결과를 텔레그램 메시지 형식으로 포맷팅해 발송한다
7. 발송에 성공하면 최종 선정된 item id들을 발송 이력 DB에 기록한다
8. 각 단계 결과(검색 건수, 후보 풀 크기, 최종 선정 건수, 발송 성공 여부)를 로그로 남긴다

## 6. 성공/실패 기준
- **성공**: 스크립트가 예외 없이 종료되고 텔레그램 메시지가 정상 수신된다.
- **후보 부족**: 한쪽 카테고리 후보가 5건 미만이어도 실패로 보지 않고, 있는 만큼 발송한다
  (5절 참고).
- **완전 실패**: HN API 호출 자체가 실패, Claude API 호출 실패, 또는 텔레그램 전송 실패 시
  원인을 알 수 있는 에러 로그를 남기고 0이 아닌 종료 코드로 종료한다.
- 이번 버전은 실패한 단계를 같은 실행 내에서 재시도하지 않는다 (Hermes/스케줄러가 다음 주기에
  다시 실행).

## 7. 제약사항 / 비범위
- 뉴스 소스는 이번 버전에서 Hacker News 1곳만 사용한다. 소스 확장(NewsAPI, RSS 등)은 범위 밖.
- 정기 실행(스케줄링) 로직은 포함하지 않는다 — Hermes 또는 OS 스케줄러가 담당.
- "Hot" 판정 점수식과 카테고리 분류 키워드 목록은 이번 버전에서 사람이 직접 정의한 규칙이며,
  운영하면서 튜닝이 필요할 수 있다 (자동 학습/조정 기능은 범위 밖).
- 한국어 요약은 Claude API 1회 호출 결과를 그대로 사용하며, 번역 품질에 대한 별도 검수
  로직은 두지 않는다.
- 발송 이력은 최근 발송 여부만 판단하며, 사용자가 특정 글을 수동으로 "다시 보내지 않음"
  목록에서 제외/포함하는 관리 기능은 범위 밖이다.

## 8. 의존성
- **외부 API/서비스**: Hacker News Algolia Search API(인증 불필요), Anthropic Messages API
  (구조화 출력, 실행당 1회 호출), Telegram Bot API
- **필요한 Python 패키지(초안)**: `requests`, `anthropic`, `python-dotenv`, `sqlite3`(표준 라이브러리)
