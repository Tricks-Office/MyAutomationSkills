# Changelog — marathon_finder

## [0.1.1]
- `ai_news_telegram`에서 겪은 HN API 응답 지연 → 타임아웃 → 스킬 실패 장애를 계기로 이
  스킬도 점검, marathonmate.store 목록 페이지 요청(무재시도 1회)이 실패하면 그 실행의
  한국 대회 전체가 누락되는 부분 데이터 손실 위험을 확인
- 목록 페이지 요청에 연결 오류/타임아웃/5xx 재시도 로직 추가 — 최대 3회 시도, 1초·2초
  지수 백오프. 4xx 응답은 재시도해도 결과가 같아 제외
- 목록 페이지 요청 타임아웃을 30초 → 45초로 상향 (대회 상세 페이지/Claude/텔레그램
  타임아웃은 그대로 유지)
- 대회 상세 페이지 요청(이미 폴백 있음), Claude API 호출, 텔레그램 발송은 재시도 대상에서
  의도적으로 제외 — 각각 폴백 존재, 중복 과금/중복 발송 우려
- PRD/SRS에 재시도 정책(SRS FR-10) 반영, 재시도 시나리오 테스트 5개 추가
